# Notion 메모 위젯

Notion 페이지(또는 그 안의 특정 섹션)를 **읽기 전용**으로 화면 한켠에 상시 표시하는 위젯입니다.
작성은 Notion 앱에서 하고, 이 위젯은 "보기"만 담당합니다.

## PC (Windows/Mac/Linux) — Electron 위젯

### 실행
```bash
npm install
npm start
```
(Windows 배포용 exe: `npm run dist`)

### 처음 설정
1. https://www.notion.so/my-integrations 에서 **새 통합 만들기** → 토큰 복사
2. 보고 싶은 Notion 페이지 → 우측 상단 `⋯` → **연결(Connections)** → 만든 통합 추가
   (이걸 안 하면 API가 페이지를 못 읽습니다)
3. 위젯 우측 상단 ⚙ → 토큰 / 페이지 URL 입력 → **연결 테스트** → 저장

### 기능
- **페이지 일부만 표시**: "표시할 섹션 제목"에 소제목(예: `오늘 할 일`)을 넣으면
  그 제목 아래부터 다음 동급 제목 전까지만 보여줍니다. 비우면 페이지 전체.
- **자동 새로고침**: 기본 15초(3초 이상 자유 설정)
- **외형 조절**: 다크 / 라이트 / 반투명 글래스, 투명도, 글자 크기, 글꼴, 강조색
- **동작 조절**: 항상 위 표시, 창 잠금(이동·크기 고정), 클릭 통과(배경처럼), 부팅 시 자동 실행
- 트레이 아이콘에서 빠른 토글 / 새로고침 / 종료
- 지원 블록: 제목, 문단, 글머리·번호 목록, 체크박스(할 일), 인용, 콜아웃, 코드, 구분선, 토글(내용 펼침)

설정은 `~/.notion-widget/config.json` 에 저장됩니다(토큰 포함, 권한 600).
