# 안드로이드 홈 위젯 (Notion 메모 보기)

안드로이드는 **진짜 홈 화면 위젯**을 만들 수 있습니다. 두 가지 경로가 있습니다.

## 경로 A) 전용 앱 직접 빌드 (권장, 완전한 위젯)

`app/` 폴더의 소스를 Android Studio로 열어 빌드하면, 홈 화면에 추가 가능한
위젯(`NotionNoteWidget`)이 생깁니다.

- 앱을 한 번 열어 **토큰 / 페이지 URL / 섹션 제목 / 새로고침 간격 / 글자 크기 / 테마**를 설정
- 홈 화면 길게 누르기 → 위젯 → "Notion 메모" 추가
- 위젯은 설정한 주기로 자동 갱신되고, 위젯을 탭하면 즉시 새로고침

> 안드로이드 홈 위젯은 배터리 보호 때문에 **최소 갱신 주기가 30분**입니다.
> 더 자주 갱신하려면 앱이 주기적으로 갱신을 예약하는 방식(WorkManager)이나,
> 위젯을 탭해 수동 새로고침하는 방식을 씁니다. 이 앱은 둘 다 지원합니다.

## 경로 B) 앱 설치 없이 빠르게 (KWGT 등)

KWGT 같은 위젯 앱의 "웹/JSON 소스" 기능으로도 가능하지만, 설정이 번거롭고
Notion 토큰을 그 앱에 넣어야 해서 권장하지 않습니다.

## 빌드 방법 (경로 A)

1. [Android Studio](https://developer.android.com/studio) 설치
2. `android/app` 폴더를 열기 (Gradle 동기화)
3. 기기를 USB로 연결하고 Run ▶ (또는 Build > Build APK 후 APK를 폰에 설치)

APK만 받고 싶다면 알려주세요 — GitHub Actions로 빌드해 릴리즈에 첨부할 수 있습니다.
